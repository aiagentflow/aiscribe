How it works

1

You code with AI Claude Code, Cursor, Codex...

Your AI writes code across 50+ files. AIScribe watches in the background.

2

Session ends, context captured

Run aiscribe log -c or let aiscribe watch auto-detect. Prompts, git diff, decisions - all captured.

3

Auto-backed up to GitHub

Every session auto-committed to your private repo. Organized by project. Full git history — browse, diff, revert any session.

4

Browse, search, never lose context

Web UI at localhost:3848. Search by meaning. Hotspot detection. Timeline view. Export for AI training.

Features

Context Capture

Auto-detects Claude Code, Codex, and Aider sessions. Captures prompts, session state, and git diff in one command.

Structured Summaries

LLM-generated summaries with risk assessment, key decisions, suspicious changes, and logical chunks.

Semantic Search

Vector embeddings for meaning-based search. Find "that refund session from last month" by describing what it did.

Hotspot Detection

Know which files change most often. Get warned about config mutations and missing tests.

Session Watch

Background watcher detects when AI sessions start and end. Auto-notifies when ready to capture.

Web UI

Dark-themed session book. Browse, search, sort, and read every session like a journal.

Git Backup

Every session auto-pushed to your private GitHub repo. Full git history of every AI decision. Browse, diff, revert.

AI Training Data

Export all your sessions as training data. Fine-tune local LLMs on your real coding patterns and decisions.

Your AI Journal, on GitHub

One command to configure. Every session auto-committed. Full git history of every AI decision you've ever made — across all your projects.

$ aiscribe remote set git@github.com:you/ai-sessions.git
Remote configured: git@github.com:you/ai-sessions.git
Repository ready.

$ aiscribe log
...summarizing...
Session recorded!
Pushed to git@github.com:you/ai-sessions.git

Set Once, Works Everywhere

Configure one remote repo. Every project's sessions auto-sync there, organized by project name. Zero config per project.

Full Git History

Every session is a commit. Browse the timeline, diff between sessions, revert to any point. Your AI's entire decision history in git.

Cross-Project View

All your projects in one repo: stripe-refunds/, auth-service/, frontend/. See your AI usage patterns across everything you build.

Private & Portable

It's your repo. Nothing leaves your GitHub account. Clone it anywhere to get your full AI context on any machine.
